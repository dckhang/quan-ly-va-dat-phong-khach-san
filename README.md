# Website Quản lý và Đặt phòng Khách sạn

Đồ án xây dựng hệ thống website hỗ trợ khách hàng tìm kiếm, đặt phòng khách sạn trực tuyến, đồng thời hỗ trợ nhân viên/quản trị viên quản lý phòng, khách hàng và đơn đặt phòng.

## Mục tiêu

- Xây dựng website hỗ trợ khách hàng tìm kiếm và đặt phòng khách sạn.
- Hỗ trợ nhân viên/quản trị viên quản lý phòng, khách hàng và đơn đặt phòng.
- Giảm thời gian xử lý và nâng cao hiệu quả quản lý so với phương pháp truyền thống.

## Đối tượng sử dụng

- **Khách hàng**: tìm kiếm, xem, đặt phòng và thanh toán.
- **Nhân viên**: xử lý đơn đặt phòng, quản lý phòng.
- **Quản trị viên**: quản lý toàn bộ hệ thống (phòng, loại phòng, người dùng, báo cáo).

## Chức năng chính

- Đăng ký / Đăng nhập
- Tìm kiếm và xem thông tin phòng
- Đặt phòng và thanh toán
- Quản lý đặt phòng (khách hàng xem/hủy, nhân viên xử lý)
- Quản trị phòng, loại phòng, người dùng (CRUD)

> Cập nhật chi tiết chức năng sau khi hoàn tất phân tích yêu cầu (CP2).

- Backend: _(điền công nghệ, VD: Node.js/Express, PHP, Java Spring...)_
- Cơ sở dữ liệu: _(VD: MySQL, PostgreSQL, MongoDB...)_

## Cấu trúc thư mục

```
.
```
