# quan-ly-va-dat-phong-khach-san
# Đồ án kỳ - Xây dựng website quản lý và đặt phòng khách sạn, cho phép khách hàng tìm kiếm & đặt phòng online, đồng thời hỗ trợ nhân viên/quản trị viên quản lý phòng, đơn đặt phòng và khách hàng.

# Mục tiêu
# Khách hàng: tìm kiếm, xem chi tiết, đặt phòng, thanh toán, quản lý đơn đặt phòng của mình
# Nhân viên/Admin: quản lý phòng, loại phòng, xác nhận đơn đặt phòng, thống kê doanh thu
# Công nghệ sử dụng
# Frontend: React / Next.js
# Backend: Node.js, Express.js
# Database: MongoDB
